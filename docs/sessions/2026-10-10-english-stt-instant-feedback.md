## Грабли

- **Открытая регистрация Supabase.** Симптом: `GET /auth/v1/settings` → `disable_signup: false`. Причина: дефолт проекта. Решение: выключено в Dashboard + `shouldCreateUser: false` у magic link (последнее не защищает от прямого вызова API, нужна именно настройка).
- **Whisper нормализует грамматику.** «tourists comes» → «come», «fino che» → «fino a che», «per miei» → «per i miei». Промпт `whisper-1` не помогает (не следует инструкциям). Решение: `gpt-4o-transcribe` + verbatim-промпт.
- **Рекомендованный `gpt-transcribe` хуже для учебной задачи.** Новее и дешевле ($0.0045/мин), но «причёсывает» (`seafoods` → `seafood` стабильно). Выбор — по тесту, а не по рекомендации.
- **Скрытое окно Chrome ломает E2E-тест.** Вкладка автоматизации в невидимом окне: `audio.play()` висит (кнопка застревает в «Говорю…»), ввод текста не доходит. Решение: окно с группой вкладок Claude должно быть на экране.
- **Тест голоса без микрофона.** Подмена `navigator.mediaDevices.getUserMedia` на поток из `AudioContext` с TTS-фразой; кнопку записи нажимать реальным кликом (user gesture для autoplay), отпускание — синтетическим `mouseup`.
- **Перепутаны ключи Supabase.** В `.env.local` в `SUPABASE_SECRET_KEY` был вставлен publishable-ключ → Storage отвечал «Object not found» (RLS как для anon), а не 401. Проверка — по префиксу (`sb_secret_` / `sb_publishable_`), не печатая ключ.
- **Auto mode запрещает прод-действия ассистенту.** Применение миграции (`supabase db query --linked`) и чтение токена Supabase CLI из Keychain заблокированы классификатором → миграции применял пользователь через `! …`, auth-настройку — в Dashboard.
- **MCP Vercel без доступа к команде** (403) — использовать `vercel` CLI.

## Принятые решения

- **Один язык на профиль**, язык снимается в сессию при создании (старые сессии не «переезжают»). Колонка `italian_level` не переименована — переименование ломает прод между миграцией и деплоем.
- **Порядок выкатки:** миграция (с дефолтами, совместимая со старым кодом) → push. Пушить до миграции нельзя.
- **`gpt-4o-transcribe`, а не `gpt-transcribe`** — 12/12 vs 11/12 сохранённых ошибок; модель меняется одной константой `STT_MODEL`.
- **Мгновенные правки — GPT-4o в том же вызове** (structured outputs), а не отдельный вызов Claude: без доп. задержки и стоимости. Цена — GPT-4o иногда ошибается в тонкой грамматике (на тесте назвал корректное итальянское «non … nessun» ошибкой); авторитетным остаётся разбор Claude в конце.
- **Правка — фраза + пояснение по-русски**, одна за реплику; режим opt-in в профиле. Принцип «ошибки в конце» остаётся дефолтом.
- **Название «Собеседник»**; репозиторий и Vercel-проект не переименованы.
